⚡ Comandos Rápidos Git & GitHub

CONFIGURACIÓN (una vez)

git config --global user.name "TuNombre" git config --global user.email "tuemail@correo.com"

CREAR PROYECTO LOCAL + GITHUB VACÍO

cd proyecto git init git add . git commit -m "Initial commit" git remote add origin URL git push -u origin main

GITHUB CON README

git clone URL cd repo git add . git commit -m "Update project" git push origin main

TRABAJO NORMAL (cada cambio)

git status git add . git commit -m "Mensaje" git push origin tu-rama

ACTUALIZARTE

git checkout main git pull origin main git checkout tu-rama git merge main

PULL REQUEST

GitHub Web → Compare & Pull Request → Merge

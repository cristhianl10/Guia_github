⚡ Comandos Rápidos Git & GitHub

CONFIGURACIÓN (una vez)

git config --global user.name "TuNombre"
git config --global user.email "tuemail@correo.com"

CREAR PROYECTO LOCAL + GITHUB VACÍO

cd proyecto
git init
📝 Aquí creas y editas tus archivos de código
git add .
git commit -m "Initial commit"
git remote add origin URL
git push -u origin main

GITHUB CON README

git clone URL
cd repo
📝 Aquí creas y editas tus archivos de código
git add .
git commit -m "Update project"
git push origin main

BUENAS PRÁCTICAS - TRABAJAR CON RAMAS

git checkout -b feature/nueva-funcionalidad
📝 Crea y cambia a una nueva rama (buena práctica: nunca trabajar directo en main)
git branch
📝 Ver en qué rama estás
git checkout main
📝 Cambiar a la rama main
git checkout nombre-de-tu-rama
📝 Volver a tu rama de trabajo

TRABAJO NORMAL (cada cambio)

git checkout -b nombre-de-tu-rama
📝 Aquí editas tus archivos de código
git status
git add .
git commit -m "Mensaje"
git push origin nombre-de-tu-rama

ACTUALIZARTE

git checkout main
git pull origin main
git checkout nombre-de-tu-rama
git merge main
📝 Aquí editas tus archivos si es necesario (resolver conflictos)
git add .
git commit -m "Mensaje"
git push origin nombre-de-tu-rama

PULL REQUEST

GitHub Web → Compare & Pull Request → Merge
